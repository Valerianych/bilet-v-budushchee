# Как починить пиксельную игру

Урок «Билет в будущее» для 8–9 класса на 40–50 минут. На интерактивной доске ребята находят ошибку в начислении очков, составляют блок-схему и проверяют исправленную игру.

[Запустить игру на доске](https://valerianych.github.io/bilet-v-budushchee/)

[Открыть конспект и рабочий лист в PDF](pdf/Конспект%20и%20рабочий%20лист.pdf)

Для работы в парах распечатайте страницу 4. Чтобы провести занятие без интернета, скачайте [HTML-файл игры](Игра%20для%20доски.html) и откройте его в браузере.
